# Revisão de Lógica de Programação em JavaScript

Este repositório reúne exercícios, notas e práticas sobre lógica de programação usando JavaScript.

## Objetivo

- Revisar conceitos fundamentais de lógica de programação.
- Praticar estruturas de controle, funções, arrays e objetos.
- Consolidar raciocínio lógico aplicado ao desenvolvimento em JavaScript.

## Como usar caso queira estudar por ele

1. Abra o arquivo `script.js` no editor.
2. Estude o exercício ou a anotação atual.
3. Execute o código no navegador ou em um terminal com Node.js.
4. Anote dúvidas e soluções no próprio README.

## Dicas de estudo

- Comece resolvendo exemplos simples.
- Separe o problema em passos menores.
- Use comentários para organizar suas ideias.
- Teste cada parte do código antes de seguir.
